* HU01 – Generación automática del archivo según la normativa



Como analista contable regulatorio, quiero que el sistema genere el archivo plano del Formato 341 siguiendo estrictamente la estructura y validaciones definidas por la SFC, para garantizar que el reporte cumpla con la normativa y sea aceptado sin errores.



* HU02 – Procesamiento en menos de 1 minuto



Como usuario encargado del reporte, quiero que el proceso de generación del archivo plano se ejecute en un tiempo máximo de 1 minuto. Para optimizar la operación regulatoria y evitar tiempos de espera excesivos.



* HU03 – Generación automática del archivo en la carpeta correspondiente



Como responsable de la entrega de reportes SFC, quiero que el archivo generado se almacene automáticamente en la carpeta configurada del sistema. Para centralizar la información y evitar que el usuario tenga que mover archivos manualmente.



* HU04 – Cálculo automático del trimestre sin ingresar fechas



Como usuario del sistema, quiero que el programa determine automáticamente el trimestre correspondiente, para evitar errores y no tener que ingresar fechas de manera manual.



* HU05 – Ejecución completa mediante Python



Como desarrollador o analista técnico, quiero que todo el proceso se ejecute íntegramente mediante Python, para facilitar el mantenimiento, la automatización y la integración futura.
